# 🛠️ Unified Tool Registry Documentation

This document provides the complete, authoritative reference for all **33 registered system tools** in the JARVIS AI OS Unified Tool Registry ([`backend/services/tool_registry.py`](file:///c:/Users/ashri/JARVIS/backend/services/tool_registry.py)).

---

## 📌 Tool Execution & Safety Architecture

Every tool call generated by the model (or Prash neural engine) is validated through a multi-tier safety pipeline:

1. **Schema & Type Validation**: Parameter types, required keys, and allowed values are enforced prior to execution.
2. **`SafetyGatekeeper` Policy Gate**: Evaluates action risk levels (`low`, `medium`, `high`, `destructive`) and intercepts prohibited terminal commands or sensitive path modifications.
3. **`ToolRegistry` Execution**: Executes asynchronous or thread-pooled handlers with isolated error handling.
4. **`ActionExecutionVerifier` Verification**: Verifies process states, window states, or return codes.
5. **`StrategyMemoryService` Feedback**: Adjusts confidence weights based on task success/failure.
