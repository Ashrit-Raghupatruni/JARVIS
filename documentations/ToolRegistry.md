## 📌 Tool Execution & Safety Architecture

Every tool call generated by the model (or Prash neural engine) is validated through a multi-tier safety pipeline:

1. **Schema & Parameter Validation**: Parameter types, required keys, and signature inspection are enforced prior to execution.
2. **`SafetyGatekeeper` Policy Gate**: Evaluates action risk levels (`low`, `medium`, `sensitive`, `destructive`) and intercepts prohibited terminal commands or sensitive path modifications.
3. **Truthful Execution**: If a tool handler is missing or uncallable, the registry strictly returns an error rather than fabricating false success.
4. **`ActionExecutionVerifier` Verification**: Verifies process states, window states, or return codes post-action.
5. **Sensitive Argument Redaction**: Automatically scrubs API keys, passwords, and secrets in execution audit logs.
